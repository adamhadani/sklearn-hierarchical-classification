# Security policy

## Supported versions

Security fixes are made on the latest release only. Upgrade to the newest version on PyPI before
reporting.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Report it privately through GitHub's
[security advisory form](https://github.com/promptromp/sklearn-hierarchical-classification/security/advisories/new)
for this repository, which only the maintainers can read. You should hear back within a week.

## Disclosure

Fixed vulnerabilities are disclosed through a published
[security advisory](https://github.com/promptromp/sklearn-hierarchical-classification/security/advisories)
alongside the release that fixes them.

## Bug bounties

There is no bug bounty programme.
